# Pizzaria da Vila

Site estático demonstrativo para uma pizzaria.

## Estrutura

- `index.html` — página principal
- `style.css` — identidade visual e responsividade
- `script.js` — abas do cardápio e menu mobile
- `img/` — imagens fornecidas

## Como abrir

Abra `index.html` diretamente no navegador.

## Observação

Este é um projeto demonstrativo. As fotos e informações comerciais são ilustrativas e não representam dados reais de um estabelecimento.

Não há carrinho, checkout, login, cadastro, pagamento, banco de dados ou backend. Os botões de pedido levam para o WhatsApp.
